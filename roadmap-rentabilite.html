Premier lot de développement

Trois corrections avant le prochain A/B.

Livrable : un environnement cohérent

  1. Extraire un moteur de prix partagé. Dans training.py et les backtests, remplacer les demi-spreads ambigus par BID/ASK explicites ; un stop LONG ne doit pas être touché quand BID_low > SL.
  2. Remplacer la référence d'equity reconstruite. Mémoriser une valorisation cohérente entre deux pas ; le bruit de stress ne doit pas être refacturé dans la récompense à chaque bougie immobile.
  3. Clarifier la fin de fenêtre. Liquider réellement et enregistrer le terminal, ou gérer une troncature avec bootstrap valide. Corriger aussi les statistiques de normalisation du fold.
  4. Relancer à configuration identique. Comparer les trades, le reward et l'entropie ; ajouter les nouvelles features dans une expérience suivante.
